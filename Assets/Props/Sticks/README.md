# Stick items

Nine distinct stick mesh objects live in `Assets/Props/Sticks.blend`. Each has a visual/placement prefab, a visible world pickup prefab, and an inventory definition. Lengths range from roughly 26–70 cm, with bark facets, lighter cut ends, and a snow-covered variant.

| Variant | Asset name | Item id |
| --- | --- | --- |
| Twig | Stick_01_Twig | twig |
| Short Twig | Stick_02_Short | stick_short |
| Long Stick | Stick_03_Long | stick_long |
| Forked Stick | Stick_04_Forked | stick_forked |
| Crooked Stick | Stick_05_Crooked | stick_crooked |
| Branching Twig | Stick_06_Branchlet | stick_branchlet |
| Thin Switch | Stick_07_Thin | stick_thin |
| Broken Stick | Stick_08_Broken | stick_broken |
| Snowy Branch | Stick_09_Snowy | stick_snowy |

Drag a prefab from **Pickups/** into a level to place a visible collectible stack. Each starts with one item; change its `ItemPickup.quantity` to author larger stacks. Every variant defaults to a stack limit of 12. Variants remain separate inventory items and retain their mesh through holding, placement, save loading, network replay, and retrieval. The original `twig` id now uses the first prefab, preserving existing save identities. The default supply spawner includes all nine variants.

**Prefabs/** contains the corresponding visual/placement prefabs, with +Y pointing out of the snow and the base at the placement origin. Each includes a **Grip** marker on the lower trunk so forks and crooked silhouettes do not shift the hand toward empty space. Meshes reference the blend import, with their authored relative sizes preserved. **Materials/** contains shared bark, warm bark, cut wood, and frost URP materials. Inventory definitions live in `Assets/Resources/Items/Sticks/`.

The editable Blender source is generated by `Tools/build_sticks.py`. Run it with the installed Blender in background mode, passing the blend output path after `--`, to recreate the initial collection. Editing the blend directly is also supported. Then use **Snowfield > Items > Build Stick Prefabs** to regenerate the visual and pickup prefabs. Regeneration overwrites generated prefab layouts and preserves existing definition tuning and material colors. **Verify Stick Prefabs** checks mesh coverage, unique catalog entries, material slots, colliders, and pickup wiring. **Preview Stick Prefabs** writes `Screenshots/Items/sticks.png` without saving changes to an open scene.
